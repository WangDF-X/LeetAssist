# 05. Timer（智能计时）Spec

- 状态：Confirmed
- 关联阶段：Phase 4
- 最后更新：2026-09-15
- 涉及代码目录：`src/sidepanel/timer/`

## 1. 目标（In Scope）

- 打开题目后，用**本地算法**（difficulty / 通过率 / 标签等，不调用 AI、零 token 消耗）估算推荐时间，并给出思考/编码/检查三段拆分。
- 计时入口位于**中间竖直工具栏**（01-extension-shell）：未开始时显示推荐值 + 开始；开始后入口文字变为**真正的倒计时**；悬停入口出现**暂停 / 结束**两个按钮。
- 点击**暂停**弹出四选项弹窗：查看完整分析 / 继续 10 分钟 / 查看 AI Hint / 结束。
- **到时**：网页通知（chrome.notifications）+ 声音 + badge 变 `!`，并**自动弹出同一个四选项弹窗**（着重显示）。
- 面板关闭/最小化时扩展图标 badge 显示倒计时；点击 badge/通知/logo 打开面板，若已超时则直接展示四选项弹窗。
- 用户永远可以覆盖/修改推荐时间（手动改时间的入口细节见第 8 节说明：自定义设置功能延后补充）。

## 2. 明确不做

- **V1 不调用 LLM 估时**（用户 2026-09-15 确认：太费 token；本地算法足够，AI 估时以后有需要再评估）。
- 手动自定义时间的设置界面**延后做**（用户确认：属于较简单的一块，后面再加）；V1 只提供算法推荐值 + 到时后的"继续 10 分钟"。
- 不做复杂学习系统/统计报表/历史趋势。

## 3. 详细需求

### 3.1 本地估时算法（v1，参数后续可调）

输入：difficulty、通过率 acceptanceRate（0–1，来自 01-extension-shell 的 ProblemMeta）、tags。

```
base = { Easy: 15, Medium: 30, Hard: 45 }               // 分钟
acceptanceFactor:
    r >= 0.60        → 0.85
    0.40 <= r < 0.60 → 1.00
    0.25 <= r < 0.40 → 1.15
    r < 0.25         → 1.30
tagFactor: tags 含 {动态规划, 图, 高级数据结构} 任一 → 1.10，否则 1.00
total = clamp(round(base * acceptanceFactor * tagFactor), 5, 120)
拆分：thinking = round(total*0.3)，checking = round(total*0.2)，coding = total - thinking - checking
```

### 3.2 计时入口与到时交互（中间工具栏形态）

- 计时入口（中间竖直工具栏的一项）：未开始时文字 = 推荐值（如 `30m`）+ 点击开始；计时中文字 = 倒计时 `12:30`，剩余 <20% 变色提醒；到时显示 `!`。
- **悬停入口出现 [暂停] [结束]** 两个按钮；点击 [暂停] → 弹出四选项弹窗（与到时同一个弹窗）。
- 四选项行为：
  - **查看完整分析** = 时间到了题目没做出来时，查看**题目的解析**（用户 2026-09-15 澄清）。V1 形态（Agent 初版稿，待用户看效果后提修改意见）：在 Agent 区展示"完整解析"视图——触发 04-ai-assistant 的 `full-analysis` 模式一次，AI 生成完整题解讲解（思路推导/算法步骤/复杂度/关键实现要点，流式渲染，明确标注为超时解析），视图底部附次级链接"打开官方题解页"（跳转当前题 leetcode.cn 题解区，零消耗）。
  - **继续 10 分钟**：deadline +10min，倒计时恢复。
  - **查看 AI Hint**：切到 Agent 区并自动触发一次"给提示"模式。
  - **结束**：停止计时，写入 `elapsed`；结束后计时 popover 内出现"查看复盘"（推荐 vs 实际、超时时长、续时时间线）。
- **到时**：WebAudio 提示音（面板打开时）+ `chrome.notifications` 网页通知（带默认声音，面板关闭时）+ badge 变 `!`；自动弹出四选项弹窗（着重显示）。
- 点击通知/badge/logo 打开面板；若已超时直接展示四选项弹窗。

### 3.3 面板最小化/关闭时的倒计时

- `chrome.action.setBadgeText` 显示剩余分钟数（如 `12`），badge 背景橙色；剩余 ≤1 分钟显示 `1`；到时显示 `!` 红色。
- 点击扩展图标打开 Side Panel（并展开计时区域）。

### 3.4 计时入口形态（中间工具栏）

- 入口为中间竖直工具栏的一项：图标 + 文字；计时中文字为倒计时，剩余 <20% 变色，到时 `!`。
- 悬停出 [暂停] [End 结束]；非计时状态点击入口打开计时 popover：三段拆分（思考/编码/检查）、开始按钮、结束后的复盘内容。

## 4. 数据结构 / 接口

```ts
interface TimerState {
  recommended: number;      // 分钟（本地算法值）
  elapsed: number;          // 秒（实际累计）
  deadlineAt?: string;      // 当前 deadline 的 ISO 时间（计时中才有）
  extendedMinutes: number;  // 累计续时分钟数
  status: "idle" | "running" | "overtime" | "ended";
  review?: {                // 结束后的复盘快照
    startedAt: string;
    endedAt: string;
    extensions: string[];   // 每次续时的时间点
  };
}
```
